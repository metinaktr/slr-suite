# Independent Usability Test Protocol

Recruit participants who were not involved in development and represent the intended research users. Obtain any institutional or ethics approval required by the host organization before collecting participant data.

Each participant should independently install dependencies, import a permitted sample, configure screening, run the workflow, locate the audit log, edit the TCCM dictionary, and identify an intentional input error. Record task completion, time, assistance, errors, and post-task System Usability Scale responses. Use anonymized participant identifiers and document recruitment, prior R experience, environment, facilitator script, and exclusion rules.

Publish aggregated results only after the protocol has been executed. This file is a protocol and is not evidence that an independent usability test has already occurred.
